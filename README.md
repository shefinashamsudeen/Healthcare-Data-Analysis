# Healthcare-Data-Analysis
## 1. Problem Statement:
- The healthcare industry generates vast amounts of data daily, providing valuable insights forhealthcare providers and policymakers to improve patient care, allocate resources effectively,and manage healthcare costs. This project aims to analyze a comprehensive healthcare datasetcomprising medical examinations, hospitalization details, and customer profiles to extractinsights into patient health profiles, medical histories, and healthcare costs. By exploringrelationships between various health metrics, identifying trends, and visualizing key patterns, weaim to deliver actionable insights to healthcare stakeholders for informed decision-makithrough rigorous data cleaning, transformation, exploration, and analysis.
## 2. Dataset Description
- The dataset comprises comprehensive patient healthcare records—encompassing demographic profiles, medical history (such as diabetes), lifestyle factors (like smoking habits), weight categories, and hospitalization charges—structured to uncover critical health trends, evaluate cost drivers, and support data-driven clinical and policy decisions.
## 3. Data Preprocessing
- Utilizing the raw records across the Medical Examinations, Hospitalization Details, and Customer Names tables, comprehensive data cleaning and transformation were performed using targeted Excel formulas. Missing values (?) were identified via COUNTIF and imputed using ROUND(AVERAGE(...), 0) and mode values, while text columns (names) were parsed, charges formatted as currency ($), Date of Birth and exact Age computed via DATE and DATEDIF, and nested IF formulas applied to derive Weight Status (from BMI) and Diabetes Status (from HbA1C).
## 4. exploratory Data Analysis
- Utilizing the cleaned dataset, exploratory analysis was conducted using Pivot Tables, summary statistics, and interactive charts to uncover key insights. A dedicated Healthcare Dashboard was built to visualize patient demographics, hospitalization cost drivers, and relationships between lifestyle factors (such as smoking and weight status) and medical conditions (like diabetes and heart issues), providing a clear visual representation of health trends and financial impacts.
